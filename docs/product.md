# 产品定位

> 一句话：录教学视频的最简工具——屏幕、人脸、声音，一个文件。

## 目标用户

- **录课的教师 / 培训师**：需要屏幕演示 + 出镜讲解 + 高质量人声，不想研究 OBS
- **教程作者 / 开发者**：录功能演示、代码 walkthrough，需要气泡摄像头和光标
- **轻量知识分享者**：不想注册云服务，文件直接落本地

非目标用户（会失望，请用别的工具）：需要后期编辑、多场景切换、直播推流、云端分享的人。

## 核心场景（Job to be done）

> "我要录一节带人脸和声音的课，现在就要开始，录完直接是一个能发出去的 MP4。"

交互对齐 Cap / 腾讯会议的「一个主窗口 + 摄像头气泡」（竞品调研见
[macos-research.md](macos-research.md)）：气泡在屏幕上的位置就是它在成片里的位置，
没有「先录再调」的心智负担。

## 范围

### v1 包含

- 全屏 / 框选区域录制（主显示器）
- 摄像头人像：角落气泡（可拖拽定位/缩放，所见即所得）+ 演讲者左/右模式
- 麦克风录制（设备可选；macOS 可选 BlackHole 等虚拟声卡间接录系统声音）
- 实时预览（所见即所录）、分轨保存（纯屏幕 / 纯人像）
- 三平台统一安装与体验（独立安装包 / 源码启动脚本；PyPI 发布待解决包名冲突——PyPI 上已有同名无关项目）

### v1 明确不做（非目标）

| 不做 | 原因 | 替代 |
|---|---|---|
| 视频编辑 / 裁剪 / 字幕 | 与「录完即所得」定位冲突，且工程量大 | 剪映 / CapCut / ffmpeg |
| 窗口捕获 | 教学视频用全屏/区域已足够；Win32 实现留在 legacy | OBS / legacy Pro |
| 系统声音直录 | 三平台都没有免权限的公开通道 | macOS: BlackHole；Win: 虚拟声卡；Linux: pulse monitor（下拉里已可选） |
| Wayland 原生捕获 | 需要 PipeWire portal，复杂度高；先明确报错 | X11 会话 / OBS |
| 多显示器选择 | v1 固定主显示器，降低几何复杂度 | 后续版本 |
| 直播推流 | 超出录制工具范畴 | OBS |

### 路线图（按优先级）

1. 硬件编码探测（Windows AMF/QSV/NVENC、Linux VAAPI），失败回退 libx264
2. 摄像头设备选择（当前固定索引 0）
3. 多显示器 / 屏幕选择
4. macOS ScreenCaptureKit 路线（需要时再评估，当前 avfoundation 够用）
5. Wayland via xdg-desktop-portal

## 成功判据

- 一位从未用过 PyRecorder 的教师，从安装到录出第一节课 **< 5 分钟**（含授权）
- 录制 30 分钟课程无丢帧风暴、无音画漂移（有 moov 校验 + pacing 测试保障）
- 「停止」到拿到可播放文件的等待 **< 3 秒**（单进程直接编码，无合并步骤）
